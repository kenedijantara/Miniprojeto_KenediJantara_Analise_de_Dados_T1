# Instruções de Execução

## Requisitos

* Python instalado
* Biblioteca Pandas instalada

## Como Executar

1. Abra o projeto no VS Code ou Google Colab.
2. Certifique-se de que o arquivo "Base Varejo.csv" esteja na mesma pasta do script Python.
3. Execute o arquivo:
analise_varejo.py

## Resultado

Após a execução será gerado o arquivo:
Varejo_Limpo.csv
contendo a base tratada e limpa.
